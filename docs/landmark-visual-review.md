# 地标实际照片与模型形制对照

本轮覆盖 **29 个独立源模型、32 处注册位置**。58 份候选中取得并实际查看 **47 份本地照片**（现代/园区30、传统17），另11份受限流或超时影响未取得。67份总资料索引仍只是文件级登记，不能等同全部像素查看或完整多立面核验。

最终模型版 `d3bd20956b7d`；注册表 SHA256 `ea87dd4d4c6c5b72e716b91b039cc78706753644791261536c44d2fbb193f668`。所有照片仅作本地资料对照，没有嵌入产品纹理或发布目录。拍摄时间未知的文件保持 null。本轮没有连续摄影测量、独立尺度控制点或32位置的3m实测验收。

## 已实施的主体修正

实际可得照片暴露并纠正的结构包括 CCTV悬挑立面/底面连续钢网、水立方凹入玻璃底层/白柱，永定门三檐、午门北侧五洞及转入翼廊的侧通道、神武门三洞、鼓楼三檐红体、钟楼双檐灰砖钟室，辟雍重檐攒尖、月坛钟楼双绿檐红砌体/贯通拱、玲珑塔白钢外框/斜撑、奥林匹克塔树枝承托/跨接，以及正阳门灰砖台基。

最后五模型的定向导出保持其注册高度、位置、footprint、朝向和高程；另24模型的96份唯一GLB SHA256保持不变。钢结构具体路线、截面、节点及未展示立面均为代表性推断，不能写成逐杆竣工复制。

最终解码门禁在 [通用GLB](../tests/reports/models.json)、[样板尺寸](../tests/reports/model-dimensions.json)、[鸟巢/水立方](../tests/reports/model-olympic-dimensions.json)、[CCTV/水立方立面](../tests/reports/model-facades.json)、[五门楼](../tests/reports/model-gates.json)、[最后五主体](../tests/reports/model-form.json)。它们验证实际构件、材料区、层级、门洞射线及包络；样板有13项定义明确尺寸通过，另4项尺寸对象/悬挑端点未验收。源预览实际查看与最终浏览器GLB视觉验收分别记录。奥塔固定源预览已包含分枝/跨接，保存于最后梁端内收到实体柱内部的接头调整之前；最后接头连续性以当前版本GLB的实体外缘、连通组件和沿梁射线证明，不将该预览冒称最终浏览器截图。
