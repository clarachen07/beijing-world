# 北京世界：2026-10-02 本地实施与验收

本轮交付真实四环边界内加500米缓冲的开放轮廓城市、奥园扩展、可复现 Blender 地标、分块加载和统一导航。本报告区分代码/数据检查、本机 GPU 浏览器测量、手机仿真，以及尚缺真实设备或独立测绘输入的项目。全城逐栋街景摄影测量不属于本轮完成条件。

冻结发布版本 `f379c023976b7b0f93a8`；城市版本 `1d91e09a9c2e8b214a4d`；模型版本 `d3bd20956b7d`。连续两次网站构建生成相同发布指纹。发布目录为 `dist/`，现已[上线GitHub Pages](https://clarachen07.github.io/beijing-world/)；发布时间和单独线上检查见[发布记录](deployment.md)。校验过的静态压缩包为 `artifacts/releases/beijing-world-f379c023976b7b0f93a8.zip`，13,029个文件、约196.6MiB（含原视频），旁附SHA256；完整代码、29份Blender源资产和原始快照保留于本工作区。

## 实施范围

- 默认故宫白天鸟瞰；平移、旋转、缩放及触控，显式自由飞行、一次性电影漫游、街景漫步。接管保留完整位姿，失焦清输入；模式与地标异步意图不会覆盖后来操作。
- 漫步使用1.6米/秒、快走4.2米/秒，真实已载入地面、建筑孔洞/水岛和独立地标碰撞代理。空中降落平滑；晚到阻挡物会取消不安全落点；高门洞可通过。
- 500米/2公里/8公里层级，Worker解码、每帧组装、父块兜底、六个下载并发、完整响应体超时、内容命名和发布版本缓存。近区碰撞与远区资源有限保留；失败可重试、已缓存区可离线、WebGL上下文可恢复。
- 29份独立米制 Blender 源模型覆盖32个注册位置，116份 GLB 包含近中远与碰撞档，Meshopt/KTX2及原创烘焙PBR材质。新增雍和宫、孔庙国子监、地坛、日坛、月坛。鸟巢补屋面膜层、椭圆开口、钢桁架、三层看台及场地；水立方补宏观泡格、鼓起法线和凹入入口；央视补悬挑外侧及底部钢网。城门、鼓钟楼补正确檐层和门洞，辟雍补双檐，月坛钟楼补门洞，玲珑塔与奥林匹克塔补识别性外框/分叉支撑，正阳门采用灰砖台基。
- 主入口只接线、启动与生命周期；城市、地标、导航、UI、环境、交通和资源各有单一所有者。网站构建消费已有资产，不访问地理服务或启动 Blender；数据/模型/视频生产独立运行。

## 卡顿定位与修复证据

早期本轮性能测量虽然p95为16.7毫秒，仍检测到路线中约10.7–11秒长任务。独立CPU定位到密集地块碰撞树：1,058栋/7,180边在原Three默认深细分下大量复制共面三角形，约28.6秒触及4GB堆上限并OOM，不能把它描述成成功构建时间。

现有限制深度、公平节点预算、缓存三角形AABB及候选去重；查询仍使用全部原始精确三角形。最终城市六个按边数排序最密真实地块构建17.4–46.2毫秒；每块81点的Capsule查询P95最大0.087毫秒、射线查询P95最大0.274毫秒。此前最密块自然GC下连续重建20次最大约86毫秒。查询覆盖每块四角和中心81点；CPU进程堆包含全部解析过的候选城市数据，不等于碰撞树独占内存。永久测试检查三角形完整、跨块暴力射线等价、门洞、水岛、晚到碰撞和失败重试。

最终CPU证据位于 `artifacts/qa/collision-cpu-final.json`，历史基线与重复重建见 `artifacts/qa/collision-cpu-{baseline,after,repeat}.json`，可用 `node --import tsx scripts/collision-benchmark.mjs` 重测。最终浏览器路线的长任务和最大帧间隔见上表，不能只引用平均帧率。
